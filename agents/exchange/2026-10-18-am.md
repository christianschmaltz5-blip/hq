# Final cross-check: Codex vs. the code (2026-10-18)

No files were changed. HEAD is `70d8842`. Codex re-read the files and accepted most of the revised priorities, so few real disputes remain.

## What we agree on

- **"Maybe" is too generous.** `verdict.py:89` gives Maybe if the $325/sf margin is at least 5% **or** the $275/sf margin is at least 10%. A deal can be Maybe while losing money at $325/sf. Tightening this is a policy change. Cloud Road doesn't justify it, because today's data shows Cloud Road as **Pass**.
- **Cloud Road numbers.**
  - Today's data: land $1,016,313, profit −$925,597 at $325/sf.
  - Using the recorded $535k sale price instead: about −$410,592.
  - Codex's earlier "Maybe, −$18k" figures were stale, and Codex has retracted them.
- **The land-cost check works in one direction only.** The county model value is about 1.9× the recorded sale. The warning only fires when the sale price is more than 1.5× the model value, so it stays silent here.
- **The 7% financing and $10k site cost are editable on the page** (`hcFin`, `hcSite`). Only `verdict.py` hardcodes them. The missing inputs are construction duration, contingency and utilities.
- **The calculator and the ranking use different math.**
  - `profitFor()` adds demolition and `(n−1)×splitCost`. `calc()` adds neither.
  - `profitFor()` also discounts the sale price on multi-home splits. `calc()` doesn't. This is Codex's catch, and I missed it.
  - Autofill uses `byRightUnits || rezoneTargetUnits` with no cap, and it ignores unreliable valuations. Cloud Road autofills to 13 homes; the ranking caps splits at 4.
  - A lead with no valuation keeps the old land price.
- **The browser hides GIS failures.** `fetchHouseComps` (html:944) never checks `r.error` or `response.ok`. An ArcGIS failure comes back as HTTP 200 with an error body, so the page shows "No home sales found" instead of a retry button.
- **A failed house-comp lookup does not block a verdict.** `verdict.py` falls back to `newBuild`, even though the log says "no verdict".
- **Several features are missing or weak.**
  - Split feasibility doesn't feed profit.
  - Comp matching ignores target home size.
  - There is no ADU or casita model.
  - `calcRent` models a whole new project, not a retained house.
- **The Maps 60 ms redraw fix is still unverified in a real browser.**

## Disputes settled by the code

- **Risk haircuts.** I said Python lacks them, as if its math were inconsistent. **Codex is right.** The haircuts go into a separate `adj` value and don't change raw profit or margin (html:2133).
- **Partial overwrite.** I said a failure at a larger radius can leave results from a smaller radius partly overwritten. **Codex is right.** A later ArcGIS error replaces earlier results with an empty array. A thrown network or JSON error returns an explicit error.
- **"Confirmed capacity."** **Codex is right.** `splitInfo()` gives an estimate. It assumes a minimum lot size when zoning is missing, so the autofill cap should be "estimated split capacity".
- **Usable area.** **My point holds.** `splitInfo` uses 0.85 and the parcel panel defaults to 80%. Codex didn't contest it.
- **Scenarios per APN.** We now agree: start with one sourced, dated price override per APN.
