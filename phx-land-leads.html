💰 Max Offer — Sell the Lot to a Builder

The most you can pay the owner and still clear your profit when you flip the lot to a builder. Built from what newly built homes nearby actually sold for (County Assessor, last 3 years).
Math: max offer = new-build home value × lot % × (1 − profit % − closing %) − demo cost (underused lots only). The 25% lot share is a rule of thumb for infill lots — confirm with a real builder; it moves every number here. Home value is a median of recent newly built single-family sales, not an appraisal; luxury areas (e.g. 85028) run far higher. Assessed value lags the market, so "cushion" shows room, not a guaranteed discount. Assumes the lot is zoned and sized for a home; lot splits are a rough ceiling (85% usable, minimum lot size from R1-x zoning, 6 lots max) and need city approval — check the zoning and lot width before counting on one.
